# sups


This is just a sample site for an idea I had about a non-profit.

I just made a website to try and figure out how I would want it to look and feel. 

There is a semi-working Log-In Page + Sign-Up page, as well as links to other areas and details about the sites

I just made this website to have a feel for what I wanted everything to look like and check how my logo will play out.


Opening the website you'll see a black background and white text. The secondary color is light blue, which i set to glow when the cursor hovers over it. This adds more of an interactive and aesthetic feel. 

The highlight color for boxes and footer is a darker gray, similar to the original black color.

Adding on I gave the site a simplistic look to try and get straight to the point.

The font is pretty basic and its set to what I thought would fit.
